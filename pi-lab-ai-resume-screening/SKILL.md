# π-Lab AI简历初筛（S/A/B/C评级）

本skill为薄包装，**完整的评级提示词以 `预推免/AI初筛提示词.md` 为单一来源**，避免双重维护。

## 用途

- 给定候选人简历（PDF/DOCX，先用MinerU转为markdown的纯文字部分），输出**唯一**字母等级 **S / A / B / C** + ≤60字理由 + 真实性风险。
- **非C**的申请者才会被转发和推荐；C为不推荐。
- 评级以**具体项目和可核验产出**为主据，技能/成绩/奖项只作弱证据。

## 工作流程

1. **转markdown**：用 `mineru-pdf` skill 的 Precision API 把简历转成 `full.md`（缓存到 `$CLAUDE_JOB_DIR/tmp/mineru/<姓名>/`，已转过的复用）。
2. **读纯文字**：只读 `full.md` 文字部分，不读图片。
3. **打分**：装入 `预推免/AI初筛提示词.md` 的完整提示词，按其第四节"决定性判断顺序"（C-first）评级，按第五节严格三行格式输出。
4. **聚合**：只解析 `等级：` 行的第一个字母（S/A/B/C）。

## 评级口径速览

- **S**（极少用，直通面试）：A全部特征 + 第一梯队成果 + 与π-Lab高度吻合。拿不准降A。
- **A**（推荐）：具体项目 + 可核验产出 + 基本功扎实 + 可迁移π-Lab。
- **B**（可推荐，边界）：有真实基础但深度/产出一般；或非名校有清晰自学实践轨迹。
- **C**（不推荐）：无具体项目证据 / 技能堆砌无支撑 / 无可迁移能力 / 信息不足 / 包装无个人贡献。**拿不准B还是C倾向判C（保守）。**
