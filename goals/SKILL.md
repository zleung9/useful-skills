# goals — 目标与待办管理系统

## 核心概念

所有待办/任务目标都有**两个维度**：

| 维度 | 说明 |
|------|------|
| **时间维度** | 年度 → 季度 → 月度 → 周 → 今日 |
| **优先级维度** | 重要且紧急 / 重要不紧急 / 紧急不重要 / 不紧急不重要 |

---

## 文件结构

主文件：`$WORKSPACE/GOALS.md`

```
# 🎯 目标清单

## 📅 年度目标（2026）
- [ ]

## 🌟 季度目标（2026 Q2）
- [ ]

## 📆 月度目标（2026年4月）
- [ ]

## 📌 周目标（2026年第X周）
- [ ]

## ✅ 今日待办（YYYY-MM-DD）
> 优先级：🔴高=重要且紧急 🟡中=重要不紧急 🟢低=紧急不重要 ⚪无=不紧急不重要

### 🔴 高优先级
- [ ]

### 🟡 中优先级
- [ ]

### 🟢 低优先级
- [ ]

### ⚪ 无优先级
- [ ]

## 📝 历史记录
```

---

## 使用方式

### 添加今日待办

```
用户：帮我把"提交QM申请材料"加到今日高优先级
→ 在今日待办 🔴 高优先级 下添加 checkbox
```

### 更新任务状态

```
用户：QM申请材料已提交
→ 找到对应任务，改为 ✅ 已完成
→ 移动到历史记录
```

### 添加其他时间维度目标

```
用户：这个季度我想发2篇论文
→ 在季度目标下添加 checkbox
```

### 查看当前状态

```
用户：看看今天有什么待办
→ 读取 GOALS.md，输出今日待办清单
```

### 每日回顾

```
→ 询问用户今日完成了哪些
→ 更新完成状态到历史记录
→ 清理已完成任务
```

---

## 系统提示词（每次Goals相关交互时自动注入）

当用户提到"待办"、"任务"、"目标"、"今天要做什么"、"完成了"等关键词时：
1. 读取当前 GOALS.md 文件
2. 根据用户意图执行添加/更新/查看操作
3. 修改后保存回 GOALS.md

---

## 每日心跳检查

在每日心跳（heartbeat）时，可以主动询问用户：
- 今日待办完成情况
- 是否有新的周/月/季度目标

---

## 偏好设置

- 文件位置：`$WORKSPACE/GOALS.md`
- 时间格式：`YYYY-MM-DD`
- 周格式：`第X周（周一开始）`
- 优先级 emoji：🔴🟡🟢⚪
